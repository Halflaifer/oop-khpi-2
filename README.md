# Звіт з лабораторної роботи №16

**Дисципліна:** Об'єктно-орієнтоване програмування (Java)
**Тема:** Автоматизована збірка, тестування і СІ для Java-проєкту
**Варіант:** №3 — ІоТ-моніторинг (Середнє значення)

---

## # 1. Мета роботи
Набуття практичних навичок підготовки Java-проєтку до автоматизованої збірки, запуску тестів і безперервної інтеграції, а також засвоєння базових принципів інтеграції Java-коду з native-кодом за допомогою Java Native Interface (JNI).

---

## # 2. Опис предметної області та технологій
Для системи ІоТ-моніторингу показників датчиків було визначено необхідність розрахунку середнього арифметичного значення температур за допомогою двох різних підходів:

* **Java-сервіс (Еталонний)** — високорівнева реалізація алгоритму засобами стандартних циклів мови Java для перевірки правильності обчислень.
* **Native-сервіс (JNI)** — низькорівнева реалізація того самого алгоритму мовою С++, яка виконується поза віртуальною машиною JVM та оптимізує прохід по масиву даних безпосередньо в пам'яті комп'ютера.
* **Continuous Integration (CI)** — автоматизований конвеєр перевірок у GitHub Actions, який самостійно збирає проєкт, генерує заголовочні файли, компілює С++ шар та запускає тести при кожному оновленні коду.

---

## # 3. Реалізація модели
У проєкті реалізовано три конкретні класи та один зовнішній модуль:

1. **SensorData** (Модель даних) — об'єкт, що представляє інженерний артефакт моніторингу: зберігає унікальний ідентифікатор ІоТ-датчика, поточне числове значення показника та часову мітку зняття параметрів.
2. **DataProcessor** (Java-обробник) — реалізує стандартну бізнес-логіку обчислення середнього значення за допомогою ітерації по колекції об'єктів Java.
3. **NativeDataProcessor** (JNI-міст) — Java-клас, який містить статичний блок завантаження платформно-залежної бібліотеки через `System.loadLibrary` та оголошує `native`-метод для передачі чистих масивів примітивів у С++ шар.
4. **nativecalc.cpp** (C++ реалізація) — зовнішній native-модуль, який приймає дані з JVM, транслює їх у сирі покажчики, обчислицює результат на рівні процесора та звільняє пам'ять купи, виключаючи ризик витоку ресурсів.
