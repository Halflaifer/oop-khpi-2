Лабораторна робота №2

Вимоги до класу. Агрегація. Композиція.

Опис предметної галузіПредметною галуззю обрано систему обліку рейсів та пасажирів автобусного перевізника. 

Програма призначена для керування розкладом, призначення водіїв на маршрути та контролю використання автобусного парку.

Сформовані вимоги до системиНа основі аналізу було виділено наступні вимоги для 12 варіанту:

Система повинна дозволяти одному водію обслуговувати кілька різних рейсів (зв'язок 1 до багатьох).

Кожен рейс обов'язково має бути закріплений за конкретним автобусом (агрегація).

Система має забезпечувати можливість перегляду списку всіх рейсів, які виконує певний водій.

Зміни у структурі порівняно з першою роботоюУ першій лабораторній роботі класи були лише первинними ескізами.

У другій роботі структуру було уточнено для реалізації зв'язків між класами:Реалізація асоціацій
Клас Driver тепер містить динамічний список об'єктів класу Route (List). Це дозволяє водію "знати" про всі призначені йому маршрути.Агрегація
Уточнено зв'язок між рейсом та автобусом. Тепер об'єкт Route містить посилання на об'єкт Bus. Це дозволяє моделювати ситуацію, де автобус є частиною рейсу, але існує як окрема сутність.Інкапсуляція
Усі поля класів залишаються прихованими (private). Додано методи для роботи зі списками, що дозволяє безпечно додавати нові рейси до графіка водія.
