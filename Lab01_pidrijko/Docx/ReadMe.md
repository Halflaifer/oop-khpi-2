Лабораторна робота №1: Об'єктно-орієнтоване програмування на Java
Предметна галузь: Облік рейсів і пасажирів автобусного перевізникаЦя програма моделює спрощену систему управління автобусним парком. Основна мета системи — облік інформації про транспортні засоби, водіїв та безпосередньо рейси, що виконуються перевізником.
Ключові сутності:
Bus (Автобус): представляє одиницю рухомого складу, містить дані про державний номер та пасажиромісткість.
Driver (Водій): описує співробітника компанії, включаючи його повне ім'я та стаж роботи.
Route (Рейс): центральна сутність, яка об'єднує водія та автобус для виконання поїздки до конкретного пункту призначення.
Виконані завданняУ ході роботи реалізовано наступні кроки :Аналіз предметної галузі: виділено основні атрибути та поведінку об'єктів.Проєктування класів: створено UML-діаграму у форматі PlantUML, що відображає структуру моделі.
Реалізація інкапсуляції: усі поля класів оголошені як private, доступ до них здійснюється через конструктори.Спеціальні методи: перевизначено методи toString(), equals() та hashCode() для коректного виведення та порівняння об'єктів.
Демонстрація: у класі Main реалізовано сценарій створення об'єктів та перевірки їхньої функціональності
